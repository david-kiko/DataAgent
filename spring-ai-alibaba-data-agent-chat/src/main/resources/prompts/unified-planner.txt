# DECISION LOGIC

**数据源选择逻辑**:
1. **纯数据库场景**: 如果只有数据库schema，优先使用SQL查询
2. **纯CSV场景**: 如果只有CSV文件，使用Python进行数据分析
3. **混合场景**: 如果同时有数据库和CSV，根据问题复杂度选择：
   - 简单查询 → 优先SQL
   - 复杂分析 → 使用Python整合多数据源
4. **无数据源**: 如果没有任何数据源，建议用户提供数据

# EXECUTION RULES

1. **SQL查询规则**:
   - 列名必须使用英文，不能使用中文
   - 使用正确的MySQL日期函数
   - 避免使用MySQL不支持的函数

2. **Python代码规则**:
   - 生成完整可执行的Python代码
   - 包含必要的数据处理步骤
   - 输出结构化的分析结果

3. **混合分析规则**:
   - 先执行SQL获取数据库数据
   - 再使用Python整合CSV数据

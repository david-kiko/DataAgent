# STEP TYPES

## CSV_SCHEMA_NODE
- **Purpose**: Parse CSV file structure and extract metadata
- **When to use**: Always as the first step for CSV analysis
- **Expected output**: CSV file schema information including columns, data types, and sample data

## CSV_ANALYZE_NODE  
- **Purpose**: Generate Python code for data analysis
- **When to use**: After schema parsing, before code execution
- **Expected output**: Complete Python analysis code
- **Parameters**: 
  - analysisType: "descriptive" | "statistical" | "visualization" | "custom"
  - focusAreas: ["area1", "area2"]

## PYTHON_EXECUTE_NODE
- **Purpose**: Execute the generated Python code
- **When to use**: After code generation
- **Expected output**: Analysis results and visualizations

## REPORT_GENERATOR_NODE
- **Purpose**: Generate final analysis report
- **When to use**: After all analysis steps are completed
- **Expected output**: Comprehensive analysis report
